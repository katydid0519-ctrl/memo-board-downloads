# 메모 보드 다운로드 페이지

다운로드 페이지는 Windows x64 EXE 1.10.0과 macOS Apple Silicon·Intel ZIP 및 Linux x64 AppImage 1.10.1을 안내합니다. 모든 버튼은 같은 저장소의 공개 GitHub Release 파일을 가리킵니다. 각 버전의 SHA-256 목록을 함께 제공합니다.

Netlify에서 GitHub 저장소 `katydid0519-ctrl/memo-board-downloads`를 연결하고 운영 브랜치로 `main`을 선택하세요. `netlify.toml`이 게시 폴더 `site`를 지정합니다. 빌드 명령은 비워 둡니다.

새 버전을 게시할 때는 GitHub Release에 검증한 설치 파일과 SHA-256 목록을 올린 뒤 `site/index.html`의 표시 버전과 링크를 함께 변경합니다.
